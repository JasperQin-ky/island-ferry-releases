# IslandFerry

IslandFerry 是一款面向 macOS 的效率工具，将文件暂存区与剪贴板管理器整合为一个轻量、常驻、随手可用的工作空间。

## 为什么选择 IslandFerry

在日常工作中，很多内容其实只需要一个临时落脚点，方便你稍后继续使用。

例如：

- 你想把几个文件拖到聊天窗口里，但它们还没整理齐
- 你刚复制了一段文字、一个链接或一张图片，稍后还要再次粘贴
- 你想先临时收集几份资料，之后再统一整理
- 你经常需要在多个应用之间来回搬运文件和内容

IslandFerry 正是为这种高频、碎片化、跨应用的工作流而设计的。

它把屏幕顶部变成一个随时待命的效率中转站：

- 左侧是 `Shelf`，用于临时存放文件和文件夹
- 右侧是 `Clipboard`，用于保存和管理你复制过的内容

## 使用方式

### 1. 文件暂存区：让拖拽操作更顺手

- 直接拖入文件和文件夹，随时再将它们拖回 Finder（复制）、聊天窗口或其他应用
- 按住 `Cmd` 键再进行拖拽，可将原文件移动到 Finder 的其他位置
- 快速打开原文件，或在 Finder 中定位它
- 一键在 Terminal 中打开文件夹项目

适合这些场景：

- 发送文件前，先集中整理一批附件
- 临时汇总多个素材，再统一分发
- 做项目时，把“处理中”的文件先停靠在一个固定位置

### 2. 剪贴板管理：真正留住你复制过的内容

- 在 `设置` 中开启自动收集后，每次复制时都会自动保存内容
- 或者仅在按下专属快捷键 `Control + X` 时采集，减少不必要的打扰
- 支持重命名、标记重要、搜索、筛选和删除内容
- 清理非重要项目，只保留真正有价值的片段
- 为特定应用设置忽略规则，避免采集敏感或无意义的复制内容

### 我们正在持续优化并添加新的功能，欢迎继续关注。一旦有新版本发布，我们会第一时间为你带来最新动态。

## 安装

**系统要求：**

- macOS **14 Sonoma** 或更高版本
- Apple Silicon 或 Intel Mac

***

### 方式一：手动下载安装

<a href="https://github.com/JasperQin-ky/island-ferry-releases/releases/latest/download/IslandFerry-v0.1.0.dmg" target="_self"><img width="200" src="https://github.com/user-attachments/assets/e3179be1-8416-4b8a-b417-743e1ecc67d6" alt="Download for macOS" /></a>

下载完成后，打开 `.dmg`，然后将 **IslandFerry** 拖到 `/Applications` 文件夹中。

> \[!IMPORTANT]
> 由于我们暂时还没有 Apple Developer 账号，macOS 在首次启动时会提示 IslandFerry 来自“身份不明的开发者”。这是正常现象。
>
> 在应用可以正常打开前，你需要先绕过这一步。这个操作只需要做一次，任选以下任一方法即可。

***

#### 推荐方式：使用终端（始终有效）

这是最快、最省事的方法。只需要执行一条命令，而且对所有用户都比较稳定。相比之下，系统设置中的方式有时可能无效，对非管理员用户也不一定适用。

将 IslandFerry 移动到 Applications 文件夹后，运行：

```bash
xattr -dr com.apple.quarantine /Applications/IslandFerry.app
```

然后正常打开应用即可。

***

#### 备选方式：通过系统设置

> \[!NOTE]
> 这种方法并不适用于所有用户。如果无效，请使用上面的终端方式。

1. 先尝试打开应用，此时你会看到安全提醒。
2. 点击 **OK** 关闭提示。
3. 打开 **系统设置** > **隐私与安全性**。
4. 滚动到页面底部，找到 IslandFerry 的提示并点击 **仍要打开**。
5. 如有弹窗，继续确认即可。
