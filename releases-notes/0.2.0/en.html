IslandFerry v0.2.0

New Features

    Clipboard

  • Added three privacy settings
  • Sensitive content protection: When enabled, detected sensitive content will be blurred; viewing and copying require Touch ID authentication
  • Password or sensitive data detection: Do not save when detecting private key text, JWT, known token prefixes, credential key-value pairs
  • Bank card number, ID number detection: Do not save when detecting bank card numbers, ID numbers, passport numbers, etc.
