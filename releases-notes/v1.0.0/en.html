🚀 IslandFerry V1.0.0 Feature Overview

📦 File Shelf

A lightweight file transit hub that makes common drag-and-drop actions smoother. Perfect for files you need "right now" but don't want to organize into a permanent folder just yet.
  • 📁 Drag files and folders in directly, then drag them back to Finder (copy), chat windows, or other apps anytime
  • ⌘ Hold the Cmd key while dragging to move the original file to a different location in Finder
  • ⚡ Quickly open the original file or reveal it in Finder
  • 💻 One‑click to open a folder in Terminal
Use cases: Gather attachments before sending an email, temporarily collect multiple files before redistributing them, or keep “work‑in‑progress” files docked in a fixed place.

📋 Clipboard Manager

Actually preserve what you've copied. The system clipboard only keeps the last item you copied. IslandFerry’s clipboard history saves important content for later use and management.
  • 🤖 Enable auto‑collection in settings to automatically save content every time you copy
  • ⌨️ Or only collect when you press the dedicated shortcut Control + X to avoid unnecessary distractions
  • ✏️ Rename, star, search, filter, and delete items
  • 🗑️ Clean up unimportant items and keep only what truly matters
  • 🚫 Set ignore rules for specific apps to avoid capturing sensitive or meaningless copies
Makes IslandFerry more than just a “clipboard history” – it’s a manageable content stash.
