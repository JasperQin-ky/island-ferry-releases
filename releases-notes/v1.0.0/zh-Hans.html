🚀 IslandFerry V1.0.0 功能速览

📦 文件暂存区

轻量的文件中转站，让常用拖拽动作变得更顺手。适合处理“马上要用，但现在不想整理到正式目录”的文件。
  • 📁 直接拖入文件和文件夹，随时再将它们拖回 Finder（复制）、聊天窗口或其他应用
  • ⌘ 按住 Cmd 键再进行拖拽，可将原文件移动到 Finder 的其他位置
  • ⚡ 快速打开原文件，或在 Finder 中定位它
  • 💻 一键在 Terminal 中打开文件夹项目
适合场景：发文件前集中整理附件、多个素材临时汇总后统一分发、将“正在处理中的文件”停靠在一个固定位置。

📋 剪贴板管理

把复制过的内容真正存下来。系统剪贴板只能保留最近一次复制，IslandFerry 的剪贴板历史会把重要内容留下，方便稍后继续使用和管理。
  • 🤖 在设置中开启自动收集后，每次复制时自动保存内容
  • ⌨️ 或仅在按下专属快捷键 Control + X 时采集，减少不必要的打扰
  • ✏️ 支持重命名、标记重要、搜索、筛选和删除内容
  • 🗑️ 清理非重要项目，只保留真正有价值的片段
  • 🚫 为特定应用设置忽略规则，避免采集敏感或无意义的复制内容
让 IslandFerry 不只是“剪贴板历史”，更是一个可管理的内容暂存库。
