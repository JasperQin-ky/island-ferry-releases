IslandFerry v1.1.0

✨ New Features

  • Shelf adds "Archive" feature, allowing you to quickly move one or more files into a specified folder.

⚙️ Changes & Improvements

  • The move logic for Command + Drag has been further optimized.
  • Application-type items are now automatically excluded to avoid accidental moves, with clearer prompts provided.
  • Optimized the timing of URL preview loading to reduce interference with sound alerts and interface responsiveness.

🐛 Fixes

  • Fixed an issue where some bookmarks were not correctly removed after multi-selection drag-and-drop.
  • Fixed an issue where the copy button on the right side of clipboard items occasionally failed.
  • Fixed a crash that could occur when deleting a URL item that was still being parsed.
  • Improved overall stability.
